# ☕ Coffee Shop Business Analytics

## 📌 Overview
End-to-end BI project analyzing coffee shop performance using transactional, calendar, and weather data.

## 🧠 Data Model
- Fact: Transactions
- Dimensions: Calendar, Weather
- Hour-level granularity via DateTimeKey

## ⚙️ Technical Stack
- Power BI (data modeling, dashboards)
- Power Query (data cleaning)
- DAX (KPI calculations)
- Python (data validation)

## 📊 Key Insights
- Morning peak drives majority of revenue
- Rain reduces transactions by up to 50%
- Hot beverages dominate sales (77%)

## 💡 Business Impact
Developed a simulation tool to estimate promotional impact.
